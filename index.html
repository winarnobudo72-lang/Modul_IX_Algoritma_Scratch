1 Tujuan Pembelajaran

Setelah mengikuti pembelajaran, peserta didik mampu:

  • Menjelaskan fungsi blok Motion, Events, Control, Variables, dan Operators pada Scratch.
  • Menyusun algoritma berbasis blok dengan urutan yang benar.
  • Menggunakan wait, if, dan if else untuk mengendalikan alur program.
  • Membuat dan mengubah nilai variabel serta membandingkan nilai menggunakan operator >, =, dan <.
  • Menggunakan event when green flag clicked dan broadcast / custom message untuk mengatur jalannya proyek.
  • Menguji, menemukan kesalahan, dan memperbaiki program sederhana secara mandiri.
Pertanyaan pemantik: Bagaimana membuat sprite bergerak, menunggu beberapa detik, lalu memilih tindakan yang berbeda berdasarkan nilai skor?

2 Alur Tujuan Pembelajaran (ATP)

  1. Mengenali antarmuka Scratch dan kategori blok yang digunakan.
  2. Menggerakkan sprite menggunakan blok Motion dan memulai skrip dengan Event.
  3. Mengatur jeda dan pengulangan/percabangan menggunakan Control.
  4. Membuat variabel, memberi nilai, dan memperbarui nilai selama program berjalan.
  5. Menerapkan operator perbandingan dalam kondisi if dan if else.
  6. Menghubungkan skrip dengan event broadcast/custom message.
  7. Mengembangkan proyek mini, menguji hasil, dan mempresentasikan algoritma.
Produk akhir: game mini “Misi Pengumpul Poin” yang menggerakkan sprite, menambah skor, dan menampilkan pesan sesuai skor.

3 Materi Inti

Motion

Blok untuk mengatur gerak dan posisi sprite.

move (10) steps turn clockwise (15) degrees go to x: (0) y: (0) change x by (10)

Contoh: move 10 steps menggerakkan sprite 10 langkah sesuai arah hadap.

Control

Blok untuk mengatur jeda dan percabangan.

wait (1) seconds if <kondisi> then // aksi jika benar end if <kondisi> then // aksi jika benar else // aksi jika salah end

if menjalankan aksi saat kondisi benar. if else memilih salah satu dari dua jalur.

Variables

Variabel menyimpan data yang dapat berubah, misalnya Skor, Waktu, atau Nyawa.

set [Skor v] to (0) change [Skor v] by (1) show variable [Skor v]

Gunakan “set” untuk menentukan nilai awal dan “change” untuk menambah/mengurangi.

Operators

Operator perbandingan menghasilkan nilai benar atau salah.

(Skor) > (10) // lebih besar (Skor) = (10) // sama dengan (Skor) < (10) // lebih kecil

Operator ditempatkan pada bagian kondisi blok if / if else.

Events

Event memulai skrip atau mengirim pesan ke skrip lain.

when green flag clicked when I receive [Mulai v] broadcast [Selesai v]

Broadcast mengirim pesan. Skrip lain dapat berjalan saat menerima pesan tersebut.

Custom message / broadcast

Di Scratch, buat pesan khusus melalui menu broadcast [message], pilih new message, lalu beri nama misalnya “LevelBerikutnya”. Pesan ini menghubungkan beberapa skrip.

when green flag clicked set [Skor v] to (0) broadcast [Mulai v] when I receive [Mulai v] move (10) steps wait (1) seconds if <(Skor) > (5)> then broadcast [LevelBerikutnya v] else say [Kumpulkan poin lagi!] for (2) seconds end

4 Demo Logika Program

Gunakan simulasi sederhana ini untuk memahami bagaimana kondisi if else memilih keluaran berdasarkan nilai skor.

Jika Skor lebih besar dari 5, program akan menampilkan “Level berikutnya!”
Algoritma: mulai → set Skor → periksa Skor > 5 → jika benar tampilkan “Level berikutnya”, jika salah tampilkan “Kumpulkan poin lagi”.
